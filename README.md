# 📱 SENAI Mobile

Repositório destinado ao armazenamento de **projetos, exercícios e exemplos desenvolvidos durante as aulas de Aplicações Mobile no SENAI**.

O objetivo deste repositório é servir como material de **estudo, prática e acompanhamento da evolução dos projetos**, reunindo diferentes atividades realizadas ao longo do curso.

---

## 🎯 Objetivo

O projeto foi criado para centralizar os conteúdos práticos desenvolvidos durante as aulas de programação mobile.

Aqui são disponibilizados exemplos utilizados para aprender e praticar conceitos relacionados ao desenvolvimento de aplicativos, organização de projetos, programação e construção de aplicações Android.

> 📚 Este repositório possui finalidade principalmente **educacional**, sendo recomendado para estudos, consultas e experimentação.

---

## 📂 Estrutura do projeto

Atualmente, o repositório está organizado de acordo com as turmas e seus respectivos projetos:

```text
SENAI_mobile/
│
├── TurmaA/
│   ├── MeuApp/
│
├── TurmaB/
│   └── MeuAPP/
│
└── README.md
```

## 🛠️ Tecnologias e ferramentas

Com base na estrutura atual dos projetos, são utilizados principalmente:

* ☕ **Java** — desenvolvimento do código das aplicações Android;
* 🤖 **Android** — plataforma dos projetos mobile;
* 🐘 **Gradle** — automação e gerenciamento da construção dos projetos;
* 🧩 **Gradle Kotlin DSL** — configuração dos projetos através de arquivos `.gradle.kts`;
* 🧪 **Testes Android** — estrutura preparada para testes unitários e instrumentados;
* 🧰 **Android Studio** — ambiente recomendado para abrir e executar os projetos.

Os projetos possuem estruturas `src/main`, `src/test` e, em determinados casos, `src/androidTest`, características de projetos Android organizados para desenvolvimento e testes.

## 🚀 Como utilizar

### 1. Clone o repositório

```bash
git clone https://github.com/Nisflei/SENAI_mobile.git
```

### 2. Acesse o diretório

```bash
cd SENAI_mobile
```

### 3. Escolha o projeto

Entre na pasta correspondente à turma e ao projeto que deseja estudar.

Por exemplo:

```bash
cd TurmaB/MeuAPP
```

### 4. Abra no Android Studio

Abra a pasta do projeto no **Android Studio** e aguarde o carregamento e sincronização do Gradle.

## 🤝 Contribuição

Por se tratar de um repositório educacional, novas atividades e melhorias podem ser adicionadas conforme o andamento das aulas.

Para contribuir:

1. Faça um **fork** do projeto;
2. Crie uma nova branch:

```bash
git checkout -b minha-feature
```

3. Faça suas alterações;
4. Realize o commit:

```bash
git add .
git commit -m "Adiciona nova atividade"
```

5. Envie a branch:

```bash
git push origin minha-feature
```

6. Abra um **Pull Request**.
